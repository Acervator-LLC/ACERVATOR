# Arc queue, 5 September 2026

Reference. The queue holds five arcs. Each arc is a tab. This page puts every
open issue either under one arc, or into a named group outside the arcs.

130 issues are open. Each one appears exactly once on this page.

The input is `docs/audits/2026-09-05_open_issue_audit.md`, which read every open
issue and ranked them by speed.

## The rule used

An issue belongs to an arc when finishing the arc finishes the issue. An issue
that only touches the same screen or the same file does not belong to the arc.
Two faults on one screen that need two unrelated repairs stay apart.

Two rules decide many of them with no judgement:

- Every Simulator finding belongs to arc 2.
- Every TestNet, Competition or Proof of Accumulation finding belongs to arc 5.
