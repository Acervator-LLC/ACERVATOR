Rotating the API key is a very unique process. At the end of the day,
the user needs to basically make a new key and put it in the file. This
document utilizes examples to illustrate the process, though obviously
the reader is already familiar with API management.

Firstly, it should be noted that in order to rotate the key, the user
must first log in. Very important! Then click on API Management. It's
literally the best way to do this task.

Actually, before we go on, it is worth mentioning that this is a legacy
process. Needless to say, this is not the recommended approach.
