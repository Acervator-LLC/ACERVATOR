# New User Procedure

A how-to. It takes a new owner from the first window to a running fleet, one
screen at a time.

Each page is one step. A step carries one picture, one instruction, and one line
saying what changes.

Every picture comes from the running program, and every one shows the Qt build.
When a screen changes, the next capture replaces its picture and the page stays
as it is. Two steps carry no picture, because driving them creates bots. Those
two pages say so.

## The order

This table is the order. A page's number is its place in it. A new screen gets
its own numbered page and one new row at the end of this table.

| # | page | the step |
|---|---|---|
| 1 | [The window opens](01-the-window-opens.md) | Reach the Live page. |
| 2 | [Live has no venue](02-live-has-no-venue.md) | Open the venue form. |
| 3 | [Enter the venue keys](03-enter-the-venue-keys.md) | Store a venue. |
| 4 | [Choose the engine](04-choose-the-engine.md) | Pick the trading engine. |
| 5 | [Name what it trades](05-name-what-it-trades.md) | Pick the venue and the pair. |
| 6 | [Make the fleet](06-make-the-fleet.md) | Create more bots from one. |
| 7 | [Start the fleet](07-start-the-fleet.md) | Start the bots. |

## Where the pictures sit

Each one sits in `figures/` under the name of the step that shows it.
