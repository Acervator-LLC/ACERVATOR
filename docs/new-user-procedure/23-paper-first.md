# Step 23 — Paper first

One step of the [New User Procedure](README.md) how-to.

![No fleet is loaded. Press Import Live Fleet.](figures/step-23-paper-first.png)

**Press Import Live Fleet.**

Paper runs the same bots on the same live prices, and buys nothing. It is the
rehearsal between the Simulator and Live. Import Live Fleet copies the fleet you
built across, and Start Paper Run begins.
