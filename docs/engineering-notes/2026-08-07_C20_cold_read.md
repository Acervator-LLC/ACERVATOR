## Step 4 (NF-18) is sound — and bigger than stated

The diagnosis and the line numbers are both right. `fleet_replay_controller.py:1154`:

```python
idx = int((float(ts) * 1000.0 - base_ts_ms) // step_ms)   # step_ms = 300_000 (:1121)
```

That is a slot on a gapless 5-minute ruler, computed with no candle list and no
clock. It is compared at `:932-933` against `candle_i`, which is the **MasterClock
cursor** — a position in `sorted(union)` (`master_clock.py:66-76`, `:100-103`).
Nothing converts between the two spaces.

Two amendments the plan omits:

**(a) The bound is in the wrong space too.** The panel passes
`progress.total_candles or max(len(r) for r in candles.values())`
(`fleet_replay_panel.py:1027-1029`), but `progress.total_candles` is assigned
only inside `start()` at `controller:417-418` — which runs **after**
`_build_sim()` at `:411`, and after the panel has already built anchors and
scheduled start at `panel:1090`. The `or` fallback therefore fires on **every**
run, and `n_candles` is the longest tablet's length, never the union size.

**(b) Severity — MEASURED 2026-08-07, superseding the cold read's inferred
figure.** All 35 live tablets read directly (read-only):

```
union size          61,201 candles     2026-01-01 00:00 -> 2026-08-01 18:35
longest single      61,200 candles
span in 5m slots    61,280
MISSING SLOTS       79   across exactly 3 gaps
  +1  slot  after 2026-02-19 22:15    cumulative drift  +1
  +77 slots after 2026-05-08 01:15    cumulative drift  +78   (~6.4 h outage)
  +1  slot  after 2026-05-08 19:45    cumulative drift  +79
```

**No trade is dropped on this data.** Drift (79) stays under `warmup` (100), so
`range(idx-100, idx+1)` still contains the true candle. The loss is warm-up
DEPTH: a trade after 2026-05-08 gets **21 real warm-up candles instead of
100** — a 79% truncated TA window on a harness whose entire purpose is that
simulated indicators match live ones. Before 2026-05-08 the drift is +1 and
genuinely negligible.

**Margin: 21 candles.** One more outage of that size and the anchored run
begins skipping the very candles it exists to evaluate, silently — a skipped
candle logs nothing.

**The bound half is much smaller than first stated.** Longest single series is
61,200 against a union of 61,201: the fallback bound is off by **one candle**,
not the material error the first draft of this document implied. Correcting
that overstatement here rather than leaving it to be discovered.

*A note on how this was nearly mis-sold.* The first demonstration of this defect
used a synthetic fixture whose gap pushed the trade outside the bound so it
vanished entirely — the most dramatic outcome available, and not what happens on
real data. The mechanism was proven; the magnitude was not. The pin now models
the measured 79-slot shape and asserts the true behaviour: the trade candle
survives BOTH paths, and only warm-up depth differs.

Two stale comments in that path, inherited as C20's justification:
`controller:917-918` claims anchored mode saves `15,212 → 4,258 candles (28%)`;
the most recent recorded run shows **14,598 of 15,212** — ~4% saved.
And `:921-923` says a skipped candle cannot produce a sim trade: false, the skip
path still calls `self._exchange.step()` at `:935`, which sweeps resting limit
orders and can settle a fill.
