# How I Built Acervator

Explanation. This is my own record of the work, in date order.

## 2026-04-11 — the first sitting

I started with a grid bot and threw it away the same day. A grid bot guesses
direction, and I do not want to guess. My idea was simpler. Sell the excess
above a dollar target. Buy back more on the dip. Every finished cycle leaves me
holding more coin. I wrote the first version in one sitting, and I remember it
running by nightfall.

## 2026-04-12 — a long fight with keys

Next I wired the platform to Coinbase. Key authentication cost me most of a day.
I had a live balance on screen by the end of it. I went to bed happy about it.

## 2026-08-18 — the first commit

For four months I built with no version control. On this day I put 650 files
under git in one move. From here every change carries a diff, so a reader can
check me. I should have started that way.

## 2026-09-03 — the wall

My build minutes ran out. Every run since has failed in two seconds, on billing,
not on code. I switched the merge gate off and kept working. I was angry about
it for a week.
