# Changelog

Reference. This file records every change worth a reader's attention.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Group entries under `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed` or
`Security`.

Version numbers come from git tags and GitHub releases, not from a literal in
the tree. The project is pre-1.0 and in beta, so a released version reads
`0.x.y`.
