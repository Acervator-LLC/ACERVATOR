## 4 - The desktop window's page carried only fourteen colours

### 4.1 the error

No traceback. `SKIN` in `src/gui/react_proof_of_accumulation_tab.py` is the whole
set of style names the desktop window's page writes into its `:root` rule, and it
held fourteen colours. Six of the ten a mark names were not among them, so on that
page `var(--INFO)` and five others would have resolved to nothing and the glyph
would have drawn in the inherited colour.

### 4.2 the cause

The Electron shell writes the whole style table through `design_tokens.js`. The
desktop window's page writes only the names listed in `SKIN`, by hand.

### 4.3 the correction

`SKIN` now takes every name the marks use, read from the registry itself, so the
two lists cannot drift apart.

```python
MARK_SKIN = {f"--{name}": getattr(ds, name) for name in colour_token_names()}

SKIN.update(MARK_SKIN)
```

### 4.4 the rerun

```
tokens in SKIN                    32
mark colours missing from SKIN     0
--INFO in the :root rule          True
--ACCENT_GOLD in the :root rule   True
```

## 5 - A second style name was absent, and the legend collapsed to one column

### 5.1 the error

No traceback. The legend drew one kind a column and every label was cut to nothing:
the cells read `Calx...`, `Cau...`, `Flor...`, `Elixi...`, `Ma...`, and the Vessel
row showed a glyph and a codepoint with no name at all.

### 5.2 reproduction

```
python U52_qt_grab.py 1386 2400 qt_page.png
```

### 5.3 the cause

Two faults in one rule. `grid-auto-flow: column` forced one column a kind however
narrow the zone, and the fix for it named `--SPACE_XXL`, which `SKIN` also did not
carry, so the whole `grid-template-columns` declaration was invalid and the browser
fell back to a single column.

### 5.4 the correction

`--SPACE_XXL` joined `SKIN`, the rows wrap, and the label takes the width the
codepoint does not need.

```css
grid-template-columns: repeat(
  auto-fill,
  minmax(calc(var(--SPACE_XXL) * 4px), 1fr)
);
```

### 5.5 the rerun

Two columns at the player window's width, and every label reads in full:
`Lead Ward - Saturn`, `Quicksilver Draught - Mercury`, `Cauda Pavonis - Pavonis`.

## 7 - The one control

**What a failure would mean.** If a glyph drew as an empty box, the map would show
a reader a kind it cannot name; if two kinds drew the same mark, the map would show
two things a reader cannot tell apart. Either way the map is unreadable, which is
the whole point of giving a kind a mark.

Both variants were rendered and the marks were read off the two pictures.

|---|---|---|

| families | 3 | 3 |
| absence rows | 3 | 3 |
| class rows | 7 | 7 |
| mode rows | 8 | 8 |
| `no-such-part-zz` | 0 | 0 |
