# `src/competition/action_spend.py`

The Action Budget Curve, the charge that spans turns and the PoA record store.
Two program errors came out of driving the real construction path. Both are
corrected and each rerun is below.

## Error 1, reproduction

`SharedTestnetBridge.install_on` with every path pointed at a scratch directory,
run under `python -X dev -X faulthandler` with `PYTHONWARNINGS=error`. The raise
arrives from `install_on` itself, so no call of mine was needed past
construction.

## Error 1, the cause

`install_action_spend` logged the five bands and their ratio by calling
`ActionSpend.spend_summary("")`. `spend_summary` is scoped to one event and
routes its `event_id` through `_as_identifier`, which refuses an empty string.
The install has no event, so it had no event id to pass.

## Error 1, the correction

`install_action_spend` now reads the curve from `band_rows` and `band_ratio`,
which take no event. Widening `_as_identifier` to admit an empty string was
rejected: an empty `event_id` would then reach `write_action` and key a record on
nothing, so the refusal is right and the caller was wrong.

## Error 2, the error — the pot held more than the store called spent

Two of the program's own numbers for one quantity disagreed at the end of the
run. `PoaRecordStore.event_spent` reported 0.274 and
`QuintessenceLedger.held_balance` reported 0.374 for the same event.

```
store event_spent 0.274 vs ledger pot 0.374 agree=False
```

## Error 2, reproduction

Drive `ActionSpend.act` at all five bands, then `accept_underwrite` once, then
read both numbers. The gap is exactly the underwritten 0.100.

## Error 2, the cause

`event_spent` summed only `ActionRecord.spent`. A treasury underwrite credits
`ActionRecord.underwritten` and moves the same Quintessence to the held address,
so the reader left out every unit a treasury paid. The redistribution reads this
figure, and it would have divided a pot smaller than the one that exists.

## Error 2, the correction

`event_spent` sums `spent` and `underwritten`. Both payers move Quintessence to
the held address, so the total is what rests there. The per-payer split stays on
each record, where the payer rule needs it.
