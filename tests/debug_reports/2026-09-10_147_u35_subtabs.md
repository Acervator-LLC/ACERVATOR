## 1 - The stats value column printed program syntax for the blocked metric

### 1.1 the error

No traceback. `metric_row` stringified the reading with `str`, and one of the
twenty-seven metrics holds a list. Driven with a real gate-decision payload, the value
column answered

```
blocked row value_text: "['interval', 'trend_hold', 'cash']"
```

which is Python list syntax on a screen the operator reads.

### 1.2 reproduction

```
PYTHONWARNINGS=error python -X dev -X faulthandler U35_probe.py
```

The probe calls the real `profile_metrics` and `read_metrics` over a record and a gate
decision carrying `scrum_blockers` and `fold_blockers`, then hands the reading to
`character_stats`.

```
blocked reading: ['interval', 'trend_hold', 'cash']
count_text: Metrics carrying a value: 2 of 27.
  drawn: fumble_errors = '2'
  drawn: blocked = "['interval', 'trend_hold', 'cash']"
```

### 1.3 the cause

`rpg_metrics._labels` answers `list[str]`, and `METRIC_SOURCES` names `blocked` as
`bot.gate_decision scrum_blockers and fold_blockers`. Every other metric is a number or
a word, so a single `str` call was correct for twenty-six readings and wrong for one.

### 1.4 the correction

`metric_value_text` joins a list with `STATS_VALUE_JOIN` and leaves every other reading
to `str`. `metric_row` calls it.

```python
def metric_value_text(value: object) -> str:
    if value is None:
        return STATS_VALUE_NONE
    if isinstance(value, list):
        return STATS_VALUE_JOIN.join(str(member) for member in value)
    return str(value)
```

### 1.5 the rerun

Same command, same payload.

```
blocked row value_text: 'interval, trend_hold, cash'
count_text: Metrics carrying a value: 2 of 27.
  drawn: fumble_errors = '2'
  drawn: blocked = 'interval, trend_hold, cash'
```

The red came from the ordinary development cycle. Nothing was planted, and the
difference between the two runs is the only change to that function.

## 2 - The map refusal sentence could never draw

### 2.1 the error

No traceback, and no pixel. The first map panel drew a refusal line, and
`selectedSubtab` falls back to the payload's own subtab whenever the chosen entry is
unreachable. The map panel therefore only draws under a mode that carries a map, where
the refusal is the empty string, and the sentence explaining the refusal had nowhere to
appear.

### 2.2 reproduction

Reading the two functions together. The map panel is drawn by
`SUBTAB_BODY["map"]`, which `SubtabArea` reaches only for the selected name, and
`selectedSubtab` never answers `map` for a mode whose `has_map` fails.

### 2.3 the cause

The refusal belongs beside the control that was refused, not inside the panel that
refusing prevents.

### 2.4 the correction

`MapControl` in the player window draws the button and the refusal sentence together.
`MapPanel` draws the absent-world sentence alone.

### 2.5 the rerun

The refusal sentence is now on the page in both smash modes, read off the rendered
document.

```
Monster Smash carries no map, so this subtab does not open. Dungeon Crawl and Raid do.
Team Based Monster Smash carries no map, so this subtab does not open. Dungeon Crawl
and Raid do.
```

## 3 - The driver read nothing back from the page

### 3.1 the error

```
TypeError: the JSON object must be str, bytes or bytearray, not NoneType
  File "U35_render.py", line 83, in collect
    "counts": json.loads(read(app, view, COUNT_JS % json.dumps(PARTS))),
```

### 3.2 reproduction

```
ACERVATOR_VARIANT=qt QT_QPA_PLATFORM=offscreen PYTHONWARNINGS=error
python -X dev -X faulthandler U35_render.py U35_base_qt.json
```

### 3.3 the cause

The wait loop called `processEvents` with no delay, so four thousand turns finished in
milliseconds while a `runJavaScript` answer needs a round trip to the render process.
The loop gave up and returned None, which the caller read as an answer.

### 3.4 the correction

The wait runs a real `QEventLoop` with a `QTimer` deadline, and `read` raises when the
callback never fires rather than answering None.

### 3.5 the rerun

Same command. The run reports the tab titles, the panel class and the element counts.

```
tabs ['Live', 'Charts', 'Inspector', 'Console', 'Swarm', 'Accumulation', 'Status',
'History']
panel ProofOfAccumulationReactPanel chain live
```
