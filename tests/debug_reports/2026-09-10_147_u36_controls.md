## 1 - The demo chain had no fleet, so no transfer had a recipient

### 1.1 the error

No traceback. The transfer control refused with the ledger's own sentence:

```
recipient must be a non-empty address string, got ''
```

### 1.2 reproduction

```
PYTHONWARNINGS=error python -X dev -X faulthandler U36_surface_run.py
```

The run fires each control against `chain=testnet` with the operator's `bot_state.json`
present in the scratch home.

### 1.3 the cause

`fleet_records` read `chain_file(FLEET_NAME, chain)`, which resolves to
`bot_state_testnet.json` on the demo chain. No module writes that file, so the demo chain
listed no participant, named no market and offered no second wallet. The season control
filed an exclusion for an empty exchange and an empty symbol as a result.

### 1.4 the correction

A fleet is not chain state. The same bots play on either chain and only the ledger
changes, so `fleet_records` reads the one fleet file and drops its chain argument.

```python
def fleet_records(chain: str) -> dict:
    """The ``bots`` map in the fleet state file, or {} when it is unreadable.

    ``src.core.state_manager.StateManager`` writes that file; this read never
    creates it. The fleet is not chain state, so every chain reads the one file
    and a demo run lists the same participants as a live one.
    """
    del chain
    path = LEDGER_DIR / FLEET_NAME
```

`season_control` also refuses before it calls the rotation when no market is named, so an
empty exclusion can no longer be filed.

### 1.5 the rerun

Same command. The transfer now sends, and the party window draws forty slots on the demo
chain where it drew none.

```
Sent 0.001 Quint at level 1: 0.00092 received, 0.00008 bled to the platonic.
RE/USD is excluded on coinbase from season 2; season 1 is unaffected.
```

## 8 - What this does not reach

The Draw loot button was never seen to return an item. `drop_from_pool` refuses below a
pool of twelve, and `eligible_pool` builds that pool from the exchange scout the running
process polled. The page's own process polls nothing, so the pool read nought on every
press and the floor refused. `CaptureBounds.activate` is the one entry point that builds
a pool and opens a window together, and it refuses without a figure saying how much
Quintessence a market's pool holds in a window. No unit has set that figure.

The first draw of a season will be slow wherever the scout has polled. `eligible_pool`
asks the age rule once every thirteen seconds for a market it has not asked before, and
up to twenty markets are asked. The control's own note on the page says so.

Nothing is subscribed to the live fill event. The Distil button is the only path that
mints and a person has to press it.

The payout does not refuse an event where no participant scored. It divides the pot, pays
nobody and rests the whole pot as reserve, which is what `write_payout` states it does.

No control advances the season counter, and the panel says so rather than drawing one
that would claim to.
