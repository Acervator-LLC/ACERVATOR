## Error three - the TA archetype refused the point-in-polygon test

### The error

```
passed False
TA004 high 271 units mismatch: 'px' (absolute) compared against 'crossing_x'
(dimensionless).
```

### Reproduction

```
python -m dev_harness.harness.ta_archetype src/competition/world_grid.py
```

The verdict is the `passed` field on stdout. The exit code was 1 here, and
`ta_archetype` is one of the two archetypes that can report `passed=False` on exit
0, so the field is what was read.

### The cause

`ZoneRegion.holds` computed the edge crossing with a division:

```python
crossing_x = ax + (py - ay) * (bx - ax) / (by - ay)
if px < crossing_x:
```

`crossing_x` takes its value from a division, which the rule tracks as
dimensionless, and the next line compares it against a grid coordinate.

### The correction

The cross-product form of the even-odd rule, which is the published
division-free variant and compares two products of the same grid coordinates:

```python
left = (px - ax) * (by - ay)
right = (bx - ax) * (py - ay)
if (left < right) if by > ay else (left > right):
    inside = not inside
```

The sign test replaces dividing through by `by - ay`, whose sign decides which way
the inequality points. No edge divides, so the zero-divisor guard is structural
rather than written.

### The rerun

```
passed True, 0 findings, tool_availability ta-quant ok, ta-chart ok, ruff ok
```

The same geometry answers were then driven again: three participants inside the
zone across three different squares, one inside the zone's square extent and
outside the zone itself, and one well away from it.

### verify_discovery was watched failing

`PoaWorld.verify_discovery` reports a verdict, so it is an instrument and needed a
red before its green meant anything. A fact was altered at parity - one band step,
the smallest change the band admits - and then restored.

```
as written                       verified True
amount 0.568 raised to 0.569     amount_matches False, verified False
leaf replaced with 64 zeros      leaf_matches False,   verified False
seed swapped                     all three False,      verified False
restored                         verified True
```

### The band's domain is closed

`LEAF_DRAW_DIGITS` reads sixteen hex digits of the leaf, and the band's step count
is the modulus, so every draw lands in the band. Driven over 20,000 places under
one seed:

```
creature  min 0.001     max 1.000     distinct 1000  inside the band True
ore       min 0.000001  max 0.000010  distinct 10    inside the band True
avatar    min 500       max 1000      distinct 6     inside the band True
```

Both ends are reachable. A leaf of zeros draws each band's low, and a leaf whose
first sixteen digits equal the step count less one draws each band's high. A band
that cannot be built is refused: a step of zero, a high under the low, and a span
that is not a whole number of steps.

## Two things named rather than changed

A world's boundary points are written twice, once in the action arguments and once
in the event arguments, which doubles the 22 bytes a point. Every other record in
`src/competition/` is written the same way, and the event arguments are what a block
explorer shows, so the established shape was followed rather than narrowed.

`SharedTestnetBridge.reset` drops the chain and its two files and leaves every
sibling store in place, so a world record's transaction ids can outlive the chain
that held them. The rotation, the bounds and the action store already carry that
property. `verify_discovery` reads the seed and the stored fact and never the chain,
so a reset does not make a world unverifiable.
